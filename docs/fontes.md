# Fontes

As fontes estruturadas e os endereços de acesso estão em `manifests/sources.json`.

O Portal de Dados Abertos do BNDES fornece operações de financiamento, desembolsos mensais, políticas operacionais e fontes de recursos. Em 1º de setembro de 2026, as páginas desses conjuntos informavam licença Open Data Commons Open Database License (ODbL).

O IPCA é obtido na Tabela 1737 do SIDRA/IBGE. As geometrias territoriais são provenientes das malhas do IBGE, ano de referência 2024.

Os arquivos originais não são redistribuídos. Como as fontes podem ser atualizadas, uma nova execução pode produzir números diferentes do snapshot usado no artigo. Registre data de obtenção, tamanho, número de linhas e SHA-256 de cada download.
